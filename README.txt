Project Description:
The Udacity Travel Blog static website was uploaded to an Amazon S3 bucket and configured for static website hosting. Public access was enabled through the required bucket configuration and IAM bucket policy. An Amazon CloudFront distribution was then configured using the S3 static website endpoint as the origin. The website is publicly accessible through the CloudFront distribution URL above.
